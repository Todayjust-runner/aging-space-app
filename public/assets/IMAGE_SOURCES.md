# 图片素材说明

当前页面只保留与文案语义对应的本地素材，避免出现“商品名称和图片不一致”的问题。

## 当前使用原则

- 商品图必须直接对应商品名称，例如“起身支撑扶手”使用墙面扶手图，“门槛坡化垫”使用门槛缓坡图。
- 社区图必须对应帖子内容和空间；单图用于完整场景，双图用于同一问题的两个互补视角。
- 空间图只用于“空间选择”和“采集预览”的场景感知，不能在入口页提前代替用户选择空间。
- 网络公开图可以作为候选，但如果画面和文案不一致，即使是真实图片也不进入页面。

## 素材维护要求

- 替换图片时同步更新本文件和 `src/demoData.js` 中的路径或语义说明。
- 商城图保持主体清楚、无无关水印，图片内容必须直接对应商品名称和使用场景。
- 社区图可以保留用户随手拍的真实感，但必须能直接看出帖子提到的空间、动作或改造对象。

# 第一阶段开发任务

本次重构已提供可运行的核心流程、TypeScript 服务边界与独立样例模式。下列功能尚未实施，按顺序推进；每项完成后再进入下一项。

## 平台和技术栈

优先 Android，浏览器作为日常开发与调试入口。下一轮使用 Capacitor 8 封装现有 React 应用，不重写为 Flutter 或 React Native。首轮真机验收以 Android 10 及以上设备为主，覆盖一台较低配置手机和一台当前主流设备；最终最低系统版本在原生插件选型后确认。

iOS 放在后续，需要 macOS、Xcode、签名和真机测试条件。业务功能和服务接口保持平台无关，不在组件里直接调用原生 SDK。

| 层次 | 选择 |
| --- | --- |
| 前端 | React 19、TypeScript、Vite 7、原生 CSS |
| 状态 | React Context + useReducer |
| 移动容器 | Capacitor 8，下一轮接入 |
| 测试 | Vitest、React Testing Library、Playwright |
| 后端 | Python、FastAPI，一个模块化服务起步 |
| 数据与文件 | PostgreSQL、腾讯云 COS |
| 语音 | 腾讯云 ASR，经后端调用或签发短期凭证 |
| 图片评估 | 视觉模型提取证据、规则判断、必要时人工复核 |

Node.js 使用 22.12+ 的 22 LTS 系列；当前测试工具也支持 Node 24。后端和数据库不在本轮创建，API 密钥不进入前端环境变量。

## 1 安卓与真实采集

- 增加 Android 工程、开发包签名、图标及安全区和返回键处理。
- 实现 CaptureService：权限申请、相机拍照、取消、重拍及素材记录。
- 将照片保存到合适的本地文件存储，SessionStorage 只保存元数据，不保存大体积 Base64 图片。
- 验收：真机安装成功，拒绝权限和取消操作可恢复，关闭再打开能够继续草稿。

## 2 后端与用户记录

- 建立用户、家庭、住宅、空间、采集记录、评估任务、报告版本和方案清单。
- 确定鉴权及上传协议，实现对象存储受限上传和异步评估任务查询。
- AssessmentService 的 analyze 在内部完成创建、等待与结果转换，界面不依赖厂商响应格式。
- 验收：用户只能访问授权家庭的数据；失败任务可重试，旧任务不会覆盖新输入；报告保留证据和版本。

## 3 卫生间真实评估

- 先限定卫生间与明确的风险项，准备多视角采集要求、人工标注样本和独立测试集。
- 先提取事实，再结合画像和规则判断风险。照片不能确认的尺寸、材质、防滑或安装条件要求补录或人工复核。
- 同一次结果保存后不自动变动；重新分析生成新版本，记录模型、规则及证据版本。
- 验收：证据不足、冲突或未知安装条件不会输出确定安全结论或直接可执行推荐；评估对照专家标注核验。

## 4 语音输入

- 录音转文字，用户确认后填入画像或需求描述；先完成短语音，再考虑播报和连续对话。
- 根据目标地区选择普通话、粤语或多方言引擎，用老人实际录音验证；接入前核对腾讯云当前支持范围和价格。
- 验收：权限拒绝、超时、方言和识别错误均可修改或改用文字输入。

## 5 上门辅助扫描

- 用户、家属或客服预约，后台派单，工作人员按相同采集标准上传。
- 预约和服务状态独立于评估状态，明确覆盖地区、服务人员及服务责任。
- 验收：自主与上门记录归属同一住宅空间；权限隔离，预约取消和改期可追踪。

## 6 补贴入口

- 先选一个试点城市，人工核验官方政策，记录区县、对象、项目、材料、额度、有效期、来源和核验时间。
- 提供可能适用的政策、材料清单及官方跳转；资格不明时提示咨询。
- 验收：失效政策不作为当前可申请政策推荐；不承诺补贴资格，不显示未经授权的自动申请或审核结果。

3D/AR、支付、多人社区、自建模型训练和政务接口授权另行安排。

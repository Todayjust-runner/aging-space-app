- 保留画像、空间选择、采集、分析、报告、方案推荐和确认。

- Context 和 reducer 管理流程；存储、采集、评估由服务接口隔离。
- 开发默认 mock，生产默认 api；样例计算和素材只在明确样例模式使用。
- 旧样例算法保持不变，保留数值边界、证据缺失、冲突和安装条件门控测试。
- 验证组件交互、状态恢复、样例隔离、类型检查、根路径和子路径构建及四个视口。
